# Source: DeoVR CSS tokens and logo (2026-10-05)

Color tokens extracted from the production CSS bundles, plus the logo files.
Raw: [tokens](../../raw/brand/deovr-css-tokens-2026-10-05.txt), [logo SVG](../../raw/brand/deovr-logo-light.svg),
[mark PNG](../../raw/brand/deovr-logo-mark.png), [OG image](../../raw/brand/deovr-og-dark.png).

## Key facts

- Typeface: **Inter** (only font-family in the CSS).
- Primary (pink/magenta) scale: `#ff5e99` (400), `#fd4488` (500), `#f2025a` (700).
- Blue used for links, primary controls and "brand" label: `#4f95ff` (hover `#3e79d6`), light `#a8cfff`, deep `#0b1837`.
- Neutral slate scale from `#ffffff` to `#080a0c`; dark end: 900 `#1d242e`, 950 `#101419`, 1000 `#080a0c`.
- Status: positive `#4cb98a`, negative `#ff8787`, warning `#ff755f`, info `#4f95ff`.
- Feature gradients: Interactive `#f350ff→#f9b4ff`, Passthrough `#ffc061→#ffdac2`,
  Script `#51d5ff→#aff4ff`, VR Cams `#ed013a→#fe5780`.
- Logo = soft, blurred **gradient chevron / "play" mark** (coral → pink → violet → blue) + bold **"DeoVR"** wordmark.
  The SVG wordmark is dark (`#080a0c`) for light backgrounds; the mark is a raster PNG embedded in the SVG.
- Brand assets page offers PNG/SVG downloads and generic rules (keep proportions and colors, keep clear space);
  no published palette or clear-space numbers ([brand-assets](https://deovr.com/brand-assets)).
